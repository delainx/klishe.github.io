# klishe.github.io
Итоговое сочинение — это допуск к ЕГЭ, и требования к нему с каждым годом только растут. Учителя требуют литературных аргументов, а в голове после уроков литературы часто остаётся лишь «что-то про дуб».  Мы создали этот сайт, чтобы сэкономить ваше время и нервы. Здесь нет воды и пересказов на три страницы — только суть.
